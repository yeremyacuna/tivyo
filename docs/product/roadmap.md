# Product Roadmap

## v0.1.0 — Four-day MVP

### Day 1 — Foundation & Core
- Monorepo and engineering standards
- PWA foundation
- Domain model
- Priority and risk engines
- Neon/PostgreSQL foundation

### Day 2 — Data & Knowledge
- Google Calendar read integration
- Manual academic data source
- Optional Calify adapter boundary
- PDF import and text extraction
- Local knowledge index and knowledge profiles

### Day 3 — Intelligence & Briefing
- AI provider abstraction
- Workers AI adapter
- Rule-based fallback
- Morning Brief
- Configurable Web Push scheduling
- Recommended study blocks and materials

### Day 4 — Testing & Release
- Unit, integration, and end-to-end tests
- Security review
- Responsive and cross-device validation
- PDF export
- CI checks
- Documentation cleanup
- `v0.1.0` release
